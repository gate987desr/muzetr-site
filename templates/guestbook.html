留言板接入

一、本地模式（默认）：不用任何服务，留言只存在访客自己的浏览器里，适合先占个位置。

二、Giscus（推荐，免费）：留言存到你 GitHub 仓库的 Discussions 里，访客用 GitHub 账号登录后发言。

  1. 建一个公开仓库，给它开启 Discussions。
  2. 打开 giscus.app，填入仓库名，选一个 Discussion 分类。
  3. 把页面给出的 data-repo、data-repo-id、data-category-id 抄进 site.config.json 的 features.giscus。
  4. 重新 python build.py。只要 repo 不为空，这块留言板会自动换成 Giscus。

三、自建接口：如果你以后有了服务器，把 assets/js/site.js 里第 10 节的 localStorage 换成 fetch('/api/messages') 即可，页面结构不用动。
